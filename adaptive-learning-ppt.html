Problem Statement

Why Adaptive Learning Matters

Traditional e-learning is static, one-size-fits-all, and fails to adapt to individual learner needs.

🚫 The Problem

  • Static curricula ignore learner pace & gaps
  • No real-time feedback or scoring
  • Instructors can't personalize at scale
  • Learner engagement drops without adaptation

✅ Our Solution

  • Multi-agent system adapts in real time
  • RAG-powered content retrieval from training notes
  • Automated quiz generation & grading
  • Persistent learner state tracks mastery

💡 Key Insight

By decomposing the learning loop into specialized agents — intake, planning, retrieval, feedback, and tracking — we achieve modular, testable, and scalable AI-driven education.

Agent Details

Agent Breakdown

Each agent's role, runtime location, and tools

#AgentRoleLocationTools / Models
1 Intake Agent Collect learner name, topic, and level Copilot Studio Adaptive cards, topic entities
2 Planner Agent Generate personalized learning path Azure AI Foundry GPT-4o, Semantic Kernel
3 RAG Agent Retrieve curriculum from training notes Azure AI Foundry AI Search, ada-002, GPT-4o
4 Feedback Agent Generate quizzes, evaluate, and score Azure AI Foundry GPT-4o, scoring functions
5 Progress Tracker Maintain learner state and mastery levels Azure AI Foundry State store, JSON schema

Orchestration: The Planner agent acts as the orchestrator, delegating topic requests to the RAG agent and quiz results to the Feedback agent in a loop until mastery is achieved.

Conclusion

Key Learnings & Next Steps

✅ What Worked

  • Multi-agent decomposition made each component testable in isolation
  • RAG grounding reduced hallucination significantly
  • Copilot Studio provided instant no-code front-end
  • Feedback loop drove genuine learner improvement

⚡ Challenges

  • Agent-to-agent handoff latency
  • Chunk size tuning for optimal retrieval
  • State management across multi-turn sessions
  • Prompt engineering for consistent quiz quality

🚀 Future Improvements

  • Add multi-modal content delivery (images via FLUX, video summaries)
  • Implement spaced repetition scheduling across sessions
  • Dashboard for instructors to monitor cohort progress
  • Support for collaborative learning with peer agents
